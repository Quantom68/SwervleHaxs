Fair play

When you finish, Swervle sends the inputs you drove. The server replays them. If that replay does not match, the time does not count.

What is not allowed

  • A time you did not drive, or a run made by a bot
  • Changing the game so a result comes out differently
  • Interfering with someone else's race or with verification

We can remove a result, reset a name, or suspend an account when a run or a name breaks the terms.

Names

Names pass an automated filter. You can report any name on a results screen. A moderator reviews each report.

How we store runs is in Privacy and data.
